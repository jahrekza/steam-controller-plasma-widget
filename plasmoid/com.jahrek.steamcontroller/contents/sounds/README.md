# Easter egg sound

`easter-egg.ogg` is the "Wilhelm scream", cut (27.18 s – 28.48 s, level-normalised,
short fades) from:

- **"S38-01 Man eaten by alligator; screams [Wilhelm screams].wav"**
  by craigsmith on Freesound — <https://freesound.org/people/craigsmith/sounds/675810/>
- License: **Creative Commons 0** (public domain dedication).
- Part of the Sunset Editorial sound-effects library preserved by USC Cinema; the
  uploader digitised the original session recording in 2023.

To use your own sound instead, put a file named `easter-egg.mp3` / `.ogg` / `.wav` /
`.flac` in `~/.local/share/steam-controller-battery/` — it takes precedence.
